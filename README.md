# Web Application BookList


### Description
This is a web application for managing a book catalog with support for CRUD operations (Create, Read, Update, Delete). The application is built using modern technologies. The frontend is developed with **Next.js** using **TypeScript**, while the backend is implemented with **C# ASP.NET Core**, **Entity Framework**, and **PostgreSQL**. The backend follows a layered architecture with the *Repository* and *Service Layer* design patterns.

---

## Technology Stack

### Frontend:
- **React** (based on Next.js)
- **TypeScript**
- **SWR** (for state management)
- CSS/Tailwind CSS
  
### Backend:
- **C# ASP.NET Core**
- **Entity Framework Core**
- **PostgreSQL**
- **Layered Modular Architecture**
  - **Controller Layer**
  - **Service Layer**
  - **Repository Layer**
  
### Infrastructure:
- REST API for communication between frontend and backend
- Database migrations using EF Core
- Docker (optional, for containerization)
